# Generated material textures

Generated using the built-in image_gen tool. Original PNGs are stored alongside this file. Used by game3d.js with RepeatWrapping; procedural textures provide the loading/error fallback. Seamless tiling was requested but has not been verified in the rendered game.

## Prompts

### oak.png

Use case: photorealistic-natural. Asset type: square seamless repeating game material base color texture. Warm natural oak flooring, straight parallel staggered narrow planks, fine grain, subtle knots, matte finish, honey beige brown. Orthographic directly overhead scan, surface fills entire square edge to edge. Flat diffuse uniform lighting; no baked shadows, no highlights, no perspective, no vignette, no border, no text, no objects. Opposite edges must tile seamlessly. Save the generated image as a local file for use in the project.
